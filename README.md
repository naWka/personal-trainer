# Personal Trainer

Персональный тренер на агенте плюс справочник упражнений на GitHub Pages.

Агент читает историю тренировок, считает, сколько дней прошло и что уже нагружалось, и выдаёт три варианта тренировки на сегодня. Ты выбираешь один или собираешь свой. После зала пишешь отчёт — агент записывает его в историю. Со временем накапливается база, и планирование становится точнее.

---

## Как пользоваться

### Получить тренировку

Открой Claude Code в этой папке:

```
/workout
```

Можно с пожеланиями:

```
/workout хочу гирю и немного бега, час максимум
/workout спина ноет, давай что-то щадящее
```

Получишь три варианта: **A** — по логике прогрессии, **B** — альтернативный стимул, **C** — короткий на 25–35 минут.

Или просто напиши обычным текстом: «хочу пойти на тренировку».

### Записать тренировку

```
/log свинги 24кг 5х12, ТГУ 16кг 5+5, жим гантелей 22кг 3х8, потом 20 мин бега. Чувствовал себя хорошо, поясница молчала, локоть немного ныл на жиме
```

Пиши как удобно — агент распарсит, разложит по схеме и закоммитит.

### Поменять цель

Просто скажи:

> Хочу теперь набрать массу
> Готовлюсь к полумарафону через 3 месяца
> Больше не болит плечо, можно вернуть жим над головой

Агент обновит `data/profile.json`, запишет причину в `changelog` и объяснит, что изменится в тренировках.

### Посмотреть технику

Сайт-справочник: `index.html`. Локально:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Поиск, фильтры «бережёт спину» / «бережёт плечо» / «без надголовных», разбор техники по каждому упражнению и чёрный список того, что не делаем.

## Что где лежит

```
CLAUDE.md                    инструкция агента: сценарии, алгоритмы, инварианты
data/
  profile.json               кто ты, цели, ограничения, текущая фаза, бенчмарки
  history.json               история тренировок — растёт со временем
  knowledge.md               доказательная база: объём, RPE, отдых, прогрессия,
                             возврат после паузы, чёрный список. Со ссылками
  exercises/
    index.json               список файлов библиотеки
    kettlebell.json          гиря
    lower.json               ноги и таз
    push.json                жимы
    pull.json                тяги
    core.json                кор и стабилизация
    shoulder-health.json     манжета и лопатка
    mobility.json            мобильность и кинестетика
    cardio.json              кардио
index.html + assets/         справочник (GitHub Pages)
.claude/commands/            /workout и /log
```

## Как агент принимает решения

Коротко, полностью — в `CLAUDE.md` и `data/knowledge.md`.

**Считает промежуток.** `day_gap` от последней сессии. 1 день — другие паттерны или кардио. 8–14 дней — вес 85–90%, объём минус треть, калибровочная сессия. 30+ дней — блок возврата на 2–3 недели, баллистика только со второй.

**Ротирует паттерны.** Смотрит, что грузилось в последних 2–4 сессиях, и не повторяет.

**Держит объём в коридоре.** Скользящее окно 14 дней, 20–36 рабочих подходов на группу. Не хватает времени — режет подходы, а не вес: относительная интенсивность держит адаптацию даже на трети объёма.

**Автопрогрессия по RPE.** Потолок 7–8 на базе, никогда до отказа в осевых и надголовных. Гиревая баллистика заканчивается на техническом отказе, не на мышечном.

**Жёсткие фильтры безопасности.** Чёрный список не программируется никогда. Упражнения с `gated: true` — только при выполненном условии. Боль больше 3/10 снимает упражнение на месте.

## Публикация и работа с телефона

Пуш в `main` запускает GitHub Action: сначала проверка данных, потом публикация на Pages. Сломанный JSON или висячая ссылка на упражнение до сайта не доедут.

### Первая настройка

```bash
gh auth login                                        # если токен протух
gh repo create personal-trainer --public --source=. --push
gh api -X POST repos/:owner/personal-trainer/pages -f build_type=workflow
```

Дальше **Settings → Pages → Source: GitHub Actions**, если команда выше не сработала.

Сайт появится на `https://<логин>.github.io/personal-trainer/`. Открывается с телефона, работает офлайн после первой загрузки — всё локальное, внешних запросов нет.

### Попросить агента с телефона

Открой [claude.ai/code](https://claude.ai/code), подключи этот репозиторий и пиши как обычно:

> Сходил на тренировку: свинги 24 кг 5×12, ТГУ 16 кг 5+5. Поясница молчала.

Агент прочитает `CLAUDE.md`, обновит данные, прогонит валидатор и закоммитит. Action пересоберёт сайт, и через минуту изменения видны на Pages.

### Проверить данные локально

```bash
python3 scripts/validate.py
```

Проверяет: валидность JSON, регистрацию файлов в индексе, обязательные поля упражнений, висячие ссылки в заменах и прогрессиях, покрытие схемами, ссылки на архетипы поз, чёрный список, формат дат, конкретность весов в планах, разделение боли и ощущений, полноту флагов, ссылки в словаре.

### Приватность

Репозиторий публичный: история тренировок, травмы и заметки о самочувствии видны всем. Имя в `profile.json` не заполнено. Если понадобится закрыть — `gh repo edit --visibility private`, но Pages на приватном репозитории требует платного плана, и то, что уже попало в кеши поисковиков, оттуда не исчезнет.
